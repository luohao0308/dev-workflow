# 本机项目记忆

_状态：本机长期记忆 | 权威范围：个人/Agent 可复用上下文 | 更新：YYYY-MM-DD | 读取方式：按问题打开相关章节_

本目录仅保存本机或 Agent 使用的长期记忆，不是团队共同维护的项目事实源。Git 安装器会通过本机 `info/exclude` 忽略此目录；不要在其中维护团队依赖的架构、契约、Runbook 或部署规范。

> 当前任务状态以 [`docs/TASKS.md`](../TASKS.md) 为准；短期上下文与一次性会话记录留在本机。团队可复用的操作说明维护在 [`docs/operations/runbooks/`](../operations/runbooks/)；部署流水和动态环境证据保存在受控部署平台或 CI artifact。

## 维护规则

- 仅记录适合本机/Agent 长期复用且不应成为团队规范的上下文。
- 只写已经验证的经验；未复现的推断、临时决策和当前任务进度不写入这里。
- 不保存密钥、原始访问令牌、刷新令牌、密码、Cookie、私钥或完整签名 URL。
- 优先按问题组织内容，不重复编写宽泛的架构摘要。
- 优先链接源文件或现有文档，避免复制大段内容。
- 长文只检索与当前任务相关的章节；任何线上动态值都必须重新执行对应的 Preflight。

不要在这里保存凭据、秘密、个人数据、动态生产值或一次性部署记录。
