# 当前任务收尾

使用项目已有任务板作为任务权威源，不额外建立任务数据库。仅处理当前任务相关的知识，不要求每次修改同步全部文档。

逐项核实实现、自动检查、人工验收、部署、外部平台发布。每项注明完成、待处理、阻塞、不适用或未核实及证据；不适用需要任务范围依据。代码合并或 CI 成功不代表部署或正式发布。

保留真机验收、提审、外部权限等剩余工作，写明下一步和负责人（已知时）。旧部署记录不是当前线上验证，历史授权不能用于新的操作。

任务条目保留简短结果、验证与证据引用、剩余事项和阻塞。稳定事实变化时才定向更新项目摘要、规则或 Runbook；矛盾无法证实时保留 Unknown。详细过程按已有归档约定迁移并维持链接，没有约定则先提出建议。

保护用户定制和无关未提交改动。收尾本身不包含提交、推送、发布、部署或权限变更授权。
