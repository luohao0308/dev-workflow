## 维护规则

- 按日期或任务保存已经发生的过程、命令、验证结果和交付证据。
- 不在日志中保存凭据、完整环境变量或长期有效的动态地址。
- 日志与当前代码、任务或契约冲突时，日志只用于追溯。
- 可重复且已经验证的经验应提炼到 `project-memory/`，不要让后续任务依赖搜索历史日志才能操作。
- 新日志从 [TEMPLATE.md](TEMPLATE.md) 复制。
