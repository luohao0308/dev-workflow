# 容器治理专项

适用能力：`containers:oci-docker`、`containers:compose`。

本 pack 不规定必须使用 Docker；它只在 manifest 声明容器触点时提供检查。

## 最小检查

- 镜像使用可追溯且尽量不可变的基础镜像/版本，构建上下文不包含凭据、长期记忆或环境快照。
- Dockerfile/OCI 构建使用最小权限、非 root 运行（有明确例外才记录）、健康检查和合理的停止信号。
- 依赖安装锁定来源与版本；构建结果至少保留镜像 digest、源码 commit 和构建工具链身份。
- Compose 服务明确网络、卷、端口、资源、依赖健康和 secret 注入边界，不把 secret 写入镜像或仓库。
- 执行镜像漏洞、配置和供应链证明检查；失败时停止发布，不用本地 tag 代替不可变身份。

## 停止条件

无法证明镜像来源、digest、secret 边界或回滚版本时，不进入部署步骤；先补齐供应链证据。
