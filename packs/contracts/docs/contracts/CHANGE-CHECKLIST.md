# 契约变更检查清单

## 变更前

- [ ] 已确认生产者、消费者和当前权威源。
- [ ] 已判断变更是兼容、条件兼容还是破坏兼容。
- [ ] 已列出受影响的客户端、任务、数据和部署顺序。
- [ ] 已定义旧版本支持窗口、弃用信号和回滚方式。
- [ ] 涉及安全、权限、配额或敏感字段时已完成专项检查。

## 实现与验证

- [ ] 先更新源定义，不直接修改自动生成物。
- [ ] 生产者单元/集成测试通过。
- [ ] 契约测试和关键消费者回归通过。
- [ ] 错误、重试、幂等、分页、排序和空值语义已覆盖。
- [ ] 机器契约重新生成，差异符合预期。
- [ ] 新旧版本并存或迁移顺序已验证。

## 交付与收尾

- [ ] 人工指南、示例和索引已同步。
- [ ] 弃用项明确标记，不伪装成当前可用能力。
- [ ] 生成物包含可追溯的来源和版本身份。
- [ ] 发布后通过真实入口或消费者完成最小冒烟。
- [ ] 剩余消费者、兼容期限和删除任务进入 `TASKS.md`。
